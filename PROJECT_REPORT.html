ALICE HOUSE HIRIKETIYA

Dynamic Accommodation Booking Management System 🏝️

Based on Real-World Case Study: Booking.com Listing (Rating: 9.4/10 Exceptional)
Location: Wedagedara, Dodampahala, Dikwella, Matara District, Southern Province, Sri Lanka

1. Executive Summary & Project Background

The tourism and hospitality sector in Sri Lanka's southern coastal belt—particularly around the internationally celebrated horseshoe surfing haven of Hiriketiya Beach—has experienced rapid growth in boutique homestays and self-catering villas. Alice House Hiriketiya is an acclaimed, family-run guesthouse located in Wedagedara, Dodampahala, Dikwella, situated just a 10-to-12 minute stroll from Hiriketiya Beach.

While Alice House maintains a premier 9.4 / 10 ("Exceptional") rating on Booking.com, relying exclusively on third-party Online Travel Agencies (OTAs) imposes steep commission fees (15%–20%), provides limited control over customer communication, and prevents custom pricing or direct guest relationship management. This project delivers a standalone, dynamic, web-based Accommodation Booking Management System tailored specifically to Alice House Hiriketiya.

2. Problem Statement & Project Objectives

Identified Challenges

  • Heavy reliance on OTA intermediaries cutting profit margins.
  • Risk of double-booking across manual paper/message logs.
  • Lack of dynamic, live cost calculation for guests in USD & LKR.
  • Inefficient manual room inventory and reservation tracking.

Project Objectives

  • Develop a dynamic web booking engine with conflict detection.
  • Provide guest authentication and self-service reservation portal.
  • Empower guesthouse hosts with a comprehensive Admin Dashboard.
  • Ensure seamless local deployment on XAMPP (Apache, PHP, MySQL).

3. Scope of the System

The project encompasses both a customer-facing public web portal and a privileged administrator management console:

  • Public Guest Portal: Hotel overview, Booking.com room catalog with photos & amenities, date availability search, dynamic cost calculator, reservation checkout, guest account management, and verified reviews.
  • Host / Admin Console: Key performance indicators (revenue, bookings, room statuses), complete Room CRUD with file uploads, reservation workflow moderation (Pending, Confirmed, Completed, Cancelled), and review moderation.

6. Core System Modules

A. Authentication & Security Module

Enforces role-based access control (RBAC) distinguishing standard Guests from Administrators. Employs password_hash() with PASSWORD_BCRYPT and session protection.

B. Room Availability & Search Engine

Executes an overlapping date verification query: checks whether check_in < requested_checkout AND check_out > requested_checkin for non-cancelled reservations.

C. Dynamic Cost Calculation Engine

Computes elapsed nights, applies the room's nightly rate, adds cleaning/service breakdown, and converts USD to Sri Lankan Rupees (LKR) at live reference ratios.

D. Administrative Operations Module

Provides full control over property inventory: adding rooms with multipart photo uploads, adjusting rates, confirming reservations, and managing user records.

9. Relational Integrity & Cascading Rules

  • Foreign Key Enforcement: fk_bookings_user and fk_bookings_room enforce referential integrity with ON DELETE CASCADE, preventing orphaned reservation records.
  • Unique Constraints: users.email is unique, preventing duplicate account creations; bookings.booking_reference enforces unique human-readable reference tracking codes.

10. User Journey & Functional Workflows

The application provides intuitive, frictionless navigation structured around modern hospitality e-commerce standards:

Workflow A: Room Discovery & Availability Search

1. Guest accesses the Home Page or Rooms Catalog and inputs requested Check-in date, Check-out date, and Guest count.

2. The search engine queries the database, executing the availability subquery. Rooms already occupied are clearly tagged with Booked on Dates, while open rooms display Available with dynamic duration pricing.

Workflow B: Reservation & Live Dynamic Costing

1. On the Room Details page, the guest views high-resolution photography, detailed amenities (AC, Hot water, WiFi), and house rules.

2. The interactive client widget recalculates total cost in real time as dates are changed. Upon clicking "Book Now", the user is authenticated, presents special requests (e.g. scooter rental), and submits the booking.

3. The system executes an atomic transaction, allocates a unique reference (e.g. AH-202611-1042), records the initial payment schedule, and redirects to My Bookings.

Workflow C: Administrative Property Governance

1. Host Sasith logs into the Admin Portal via role-based credentials (admin@alicehouse.com).

2. The Dashboard displays total revenue, occupancy ratios, and pending reservations. With one click, the host can confirm reservations, toggle room availability for renovations, or adjust seasonal room rates.

13. Security Measures Implemented

  • SQL Injection Elimination: 100% of database interactions utilize PHP Data Objects (PDO) with parameterized prepared statements.
  • Cross-Site Scripting (XSS) Sanitization: All user-supplied inputs pass through htmlspecialchars(..., ENT_QUOTES, 'UTF-8') prior to browser rendering.
  • Session Fixation Prevention: Critical authentication transitions invoke session_regenerate_id(true) to safeguard active session tokens.
  • Secure Password Storage: Passwords stored using state-of-the-art Bcrypt cryptographic hashing algorithms.
